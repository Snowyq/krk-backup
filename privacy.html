Privacy policy

Last updated: 31 October 2026.

krk-backup is a private application used only by its owner.

  • It requests a single Google scope, drive.file, which lets it see and manage only the files it creates itself. It cannot read any other file on Google Drive.
  • It uses that access only to upload and verify backup copies of public transport data (timetables and realtime vehicle feeds) in the owner's own Drive.
  • It does not collect, store, sell or share any personal data, and does not transfer any data to third parties.
  • The access token is kept only on the owner's server. Access can be revoked at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Polityka prywatności

Aplikacja używa wyłącznie zakresu drive.file (widzi tylko pliki, które sama utworzyła), tylko do zapisu i weryfikacji kopii zapasowych danych komunikacji miejskiej na Dysku właściciela. Nie zbiera, nie przechowuje ani nie udostępnia żadnych danych osobowych. Dostęp można cofnąć w każdej chwili na myaccount.google.com/permissions.
